# Yakshvi Studios website

The public website for Yakshvi Studios, served at https://yakshvistudios.com by GitHub Pages.

## What's here

| File | What it is |
|---|---|
| `index.html` | Home page: the studio, the apps list and contact details |
| `privacy.html` | Privacy policy (Google Play links to this for each app) |
| `404.html` | Shown when a page doesn't exist |
| `CNAME` | Tells GitHub Pages to serve the site at yakshvistudios.com. Don't delete it. |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are |
| `assets/site.css` | All the styling |
| `assets/fonts/` | The Figtree font (SIL Open Font License, see `OFL.txt`) |
| `assets/logo/` | Logo files used by the pages |
| `favicon.*`, `apple-touch-icon.png` | Browser and phone icons |

## Common updates

- **Launching an app:** in `index.html`, replace the "Coming soon" card with the app's name, description, icon and Google Play link. Add a section for that app to `privacy.html` and update its "Last updated" date.
- **Changing the year:** edit `© 2026` in the footer of each page.

Changes go live a minute or two after they're committed to the `main` branch.
